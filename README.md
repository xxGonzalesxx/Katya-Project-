# DormHub — веб-сервис управления студенческим общежитием

Веб-приложение для автоматизации взаимодействия жильцов и администрации студенческого общежития: публикация объявлений и новостей, знакомство с правилами проживания, аутентификация пользователей и основа для цифровых сервисов кампуса (задачи, дежурства, бронирование, оплата).

Проект разработан в рамках дипломной работы (2026).

---

## Назначение проекта

Жизнь в студенческом общежитии требует единого и понятного канала коммуникации между студентами, комендантом и администрацией. **DormHub** объединяет информационные разделы и пользовательские сценарии в одном веб-интерфейсе:

* **Для жильцов (студентов):** быстрый доступ к актуальным новостям и объявлениям общежития, поиск по публикациям, просмотр правил проживания и вход в личный кабинет.
* **Для администрации:** управление публикациями (создание и удаление новостей), работа с учётными записями пользователей и разграничение прав доступа по ролям.
* **Для развития сервисов кампуса:** заложена база для масштабирования на дежурства, заявки, бронирование и учёт оплат.

---

## Архитектура проекта

Проект построен как **многослойное веб-приложение** с REST API на **Spring Boot**, реляционной базой данных **PostgreSQL** (запускаемой через Docker Compose) и клиентским **SPA-интерфейсом на ванильном JavaScript (ES Modules) + Bootstrap 5**.

### Общая схема взаимодействия

```text
[ Браузер (SPA: HTML / CSS / JS Modules) ]
        │
        ▼  HTTP / JSON (/api/*)
[ Spring Boot Backend ]
  ├── Controller   ──▶ приём HTTP-запросов и валидация DTO (@Valid)
  ├── Service      ──▶ бизнес-логика, маппинг DTO, хэширование паролей (BCrypt)
  ├── Repository   ──▶ доступ к данным через Spring Data JPA
  └── Entity / DTO ──▶ модели БД и контракты обмена данными
        │
        ▼  JDBC / JPA
[ PostgreSQL (Docker: katya-postgres) ]
Бэкенд (src/main/java/superchack)
config/ — конфигурация приложения (в том числе бин BCryptPasswordEncoder для безопасного хэширования паролей).

controller/ — REST-контроллеры (UserController), обрабатывающие входящие запросы и возвращающие ответы.

dto/ — объекты передачи данных (UserRequest, UserResponse) с правилами валидации (jakarta.validation.constraints) и изоляцией внутренних полей сущностей.

entity/ — JPA-сущности и перечисления предметной области (Users, AdminProfile, Role).

repository/ — репозитории на базе JpaRepository (UserRepository, AdminRepository) для работы с таблицами БД.

service/ — сервисный слой (UserService) с транзакционной логикой (@Transactional) и проверками бизнес-правил.

Фронтенд (src/main/resources/static)
index.html — единая точка входа с навигационной панелью, контейнером #app для динамического рендера страниц и футером.

js/app.js — инициализация роутера, отрисовка и обновление навбара, подсветка активных пунктов и сворачивание мобильного меню.

js/router.js — hash-маршрутизация (#/home, #/news, #/rules, #/login), разбор query-параметров, проверка прав доступа (route guards), обработка 404 и вызов функции cleanup() при смене экрана.

js/api.js — централизованный HTTP-клиент поверх fetch с таймаутом запросов, поддержкой JSON и FormData, передачей Bearer-токена и обработкой ошибок / статуса 401.

js/auth.js — управление клиентской сессией в localStorage, проверка срока действия JWT (exp), проверка ролей и синхронизация состояния между вкладками браузера.

js/ui.js — переиспользуемые UI-компоненты и утилиты (escapeHtml для защиты от XSS, skeletonCards, alert, emptyState).

js/pages/ — модули отдельных страниц и компонентов (home.js, login.js, news.js, rules.js, offer.js).

css/ — модульные стили интерфейса (style.css и компоненты).

Инфраструктура и сборка
pom.xml — сборка на Maven, Java 25, Spring Boot (spring-boot-starter-web, spring-boot-starter-data-jpa, spring-boot-starter-validation, spring-security-crypto, postgresql, lombok).

docker-compose.yml — сервис postgres (postgres:18.7, контейнер katya-postgres, база katya, порт 5432) с именованным томом katya_diplom для сохранения данных.

Быстрый старт (локальная разработка)
Запустите базу данных PostgreSQL:

Bash
docker compose up -d
Проверьте параметры подключения к БД в конфигурационных файлах (src/main/resources/application.yml и src/main/resources/db-settings/database.yml).

Соберите и запустите приложение через Maven / IDE (Main.java).

Откройте в браузере: http://localhost:8080 (или порт, заданный в настройках Spring Boot).
